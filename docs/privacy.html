Your transport empire stays yours.

This independent open-source prototype has no advertising, tracking SDK or developer analytics service. Saves, settings, imported files and tutorial progress are stored in the application container. Local diagnostic files in development builds are not uploaded automatically.

If you use original online content or multiplayer, the game connects to OpenTTD infrastructure and/or your chosen server. Those services receive ordinary network connection information and whatever player name, server listing, game or chat information you choose to share. Their operators' policies apply. Online features are optional.

Files import uses Apple's document picker. The app copies selected content into its container and applies size, path and archive checks. It does not upload your selected files to this project's developer. Files sharing or device backups you enable through the operating system are controlled by you and Apple.

You can remove local data through the app's original file/content controls where available or by removing the application. Back up saves before deletion. Public GitHub issues are public: do not attach private saves, device identifiers or credentials.

This policy describes the current source prototype. A store release must reconfirm its actual privacy declarations and linked dependencies. Questions and source: project repository.
